Pod & Deployment

Pod
Unité d'exécution de base dans K8s
Contient 1 ou plusieurs conteneurs
Deployment
Crée automatiquement les Pods
Recrée les Pods s'ils tombent

Bakery Stock Project 8 / 12

PVC : Persistance des Données MySQL

PersistentVolumeClaim
Demande de stockage persistant pour conserver les données même si le Pod est recréé
Sans PVC
Pod redémarre → Données perdues
Avec PVC
Pod recréé → Données conservées
Configuration MySQL
strategy: Recreate
Stratégie spéciale pour MySQL
Pourquoi ?
PVC en ReadWriteOnce → Pas 2 Pods simultanément
Avantage
Évite écritures simultanées sur le volume
Workflow Recreate
Arrêt ancien
→
Libération
→
Nouveau Pod

Bakery Stock Project 10 / 12

Nginx & Le Proxy /api

Problème
Le navigateur ne connaît pas les noms internes K8s !
Ces noms n'existent que dans le réseau interne du cluster
Solution
Nginx comme reverse proxy intégré au frontend
Navigateur → /api/... → Nginx → Backends internes
Règles de Proxy Nginx
Chemin NavigateurDestination K8s
/api/products backend-products-service:5001
/api/orders backend-orders-service:5002
/api/stock-usage backend-stock-usage-service:5003
Avantages
✓ Backends cachés
✓ Pas de CORS
✓ Entrée unique
